# Nitrogen-transformation potential in a landfill leachate SBR

R scripts supporting the manuscript:

**Gene-resolved metagenomics reveals partitioned nitrogen transformation potential in a landfill leachate sequencing batch reactor microbiome.**

These scripts analyse the taxonomic distribution and relative abundance of nitrogen-transformation genes using SqueezeMeta outputs. The dataset comprises three technical DNA-extraction replicates from a single sludge sample, labelled `Sample21`, `Sample22` and `Sample23`.

## Scripts

| Script | Purpose |
|---|---|
| `fig02_taxonomic_abundance_vs_nitrogen_genes.R` | Compares community abundance with the proportion of nitrogen-marker gene abundance within each taxon. Generates plots across taxonomic ranks, including the class-level comparison used in Figure 2. |
| `fig03_nitrification_heatmap.R` | Generates the nitrification gene heatmap and supporting annotation-confidence tables. |
| `fig04_denitrification_heatmap.R` | Generates the denitrification gene heatmap and supporting annotation-confidence tables. |
| `fig05_dnra_heatmap.R` | Generates the dissimilatory nitrate reduction to ammonium (DNRA) gene heatmap and supporting annotation-confidence tables. |
| `assimilatory_nitrate_reduction_heatmap.R` | Generates the assimilatory nitrate reduction (ANR) gene heatmap and supporting annotation-confidence tables. |

Figure 1 was created in BioRender and is not generated by these scripts.

## Input files

The heatmap scripts require:

- `13.1st_run.orftable`: SqueezeMeta ORF annotations, taxonomy and per-sample TPM values.
- `04.1st_run.kegg.diamond`: KEGG DIAMOND alignment results from the SqueezeMeta intermediate directory.

The DIAMOND file must contain these 12 columns, in order:

`qseqid`, `qlen`, `sseqid`, `slen`, `pident`, `alignment_length`, `evalue`, `bitscore`, `qstart`, `qend`, `sstart`, `send`.

The scatter-plot script requires a SqueezeMeta project loadable through `SQMtools::loadSQM()` and the four validation tables produced by the heatmap scripts:

- `kegg_nitrification_orf_validation_table.tsv`
- `kegg_denitrification_orf_validation_table.tsv`
- `kegg_dnra_orf_validation_table.tsv`
- `kegg_assimilatory_nitrate_orf_validation_table.tsv`

Uploading the scripts alone does not provide the required input data.

## Configuration

Before running the scripts, edit the `USER SETTINGS` section.

For each heatmap script, update:

- `orftable_file`: path to the ORF table.
- `kegg_diamond_file`: path to the KEGG DIAMOND results.
- `out_dir`: output directory.
- `samples_to_use`: sample names matching the TPM columns in the ORF table.

For the scatter-plot script, update:

- `proj`: path to the SqueezeMeta project.
- `validation_dir`: directory containing all four validation tables.
- `out_root`: output directory.
- `replicate_samples`: sample names matching the SqueezeMeta project.

The supplied paths refer to the original HPC environment and must be changed for another computer.

## Running the analyses

Run all four heatmap scripts first, as their validation tables are required by the scatter-plot script:

```bash
Rscript fig03_nitrification_heatmap.R
Rscript fig04_denitrification_heatmap.R
Rscript fig05_dnra_heatmap.R
Rscript assimilatory_nitrate_reduction_heatmap.R
```

Ensure all four validation tables are available in `validation_dir`, then run:

```bash
Rscript fig02_taxonomic_abundance_vs_nitrogen_genes.R 10
```

The argument `10` selects the ten most abundant taxa at each taxonomic rank. Taxa are selected by mean community abundance across the three technical replicates.

## Calculations

### Heatmaps

ORF TPM values are averaged across the three technical replicates. For each gene category, the summed marker ORF TPM is divided by the total ORF TPM assigned to the corresponding genus or phylum.

Heatmap colour represents:

`log10(within-taxon gene abundance + 1e-6)`

Rows include phylum summaries and resolved genus assignments. Phylum summaries include their constituent genera and should not be added to genus rows as independent observations.

### Annotation confidence

Candidate genes are identified using KEGG identifiers and annotation text, then checked for DIAMOND alignments carrying the expected KEGG identifier.

The supplied confidence settings are:

- **High:** identity ≥70% and query coverage ≥70%.
- **Medium:** identity ≥40% and query coverage ≥40%, where coverage is available.
- **Low:** an expected KEGG match that does not meet the higher confidence criteria.
- **Unvalidated:** no alignment carrying the expected KEGG identifier.

High and Medium calls also require an E-value ≤1e-5 and alignment length ≥80 amino acids where these values are available. High, Medium and Low calls contribute to the heatmaps; Unvalidated calls remain in the validation tables but are excluded from plotted abundance.

Cell letters summarise TPM-weighted annotation confidence.

### Community abundance comparison

The scatter-plot script calculates:

`100 × summed validated nitrogen-marker ORF abundance / total ORF abundance within the taxon`

ORFs occurring in multiple pathway validation tables are counted once in the combined nitrogen-marker numerator. The script prioritises TPM columns when resolving ORF abundance columns and reports the columns used.

Plots are generated for individual technical replicates and their combined mean, with versions showing or hiding unclassified taxa. Hiding unclassified taxa does not renormalise community percentages.

## Outputs

The heatmap scripts generate:

- PNG and PDF heatmaps.
- ORF-level validation tables.
- Validation summaries by gene.
- Taxon–gene abundance and confidence tables.
- Heatmap matrices and row-selection tables.

The scatter-plot script generates:

- PNG and PDF scatter plots.
- Plotting data tables.
- A combined validated nitrogen-marker catalogue.
- Technical-replicate abundance tables.
- Descriptive means and standard deviations.
- Lists of the taxa selected for plotting.

## Interpretation

These analyses describe detected genetic potential, rather than measured pathway activity. Confidence categories describe sequence annotation support. Non-detection does not establish biological absence.

The three samples are technical extraction replicates from one sludge sample. Their variation is summarised descriptively; the scatter-plot script does not perform inferential statistical tests.
